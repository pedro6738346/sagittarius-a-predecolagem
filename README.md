# 🚀 Sagittarius A — Relatório Operacional de Pré-Decolagem

## 📋 Sobre o Projeto
Este projeto simula o sistema de verificação pré-decolagem da nave espacial **Sagittarius A**.
Foram desenvolvidos algoritmos em Python capazes de analisar dados de telemetria e decidir
automaticamente entre **DECOLAGEM AUTORIZADA** ou **DECOLAGEM CANCELADA**, além de uma
análise energética e integração com inteligência artificial via API do Google Gemini.

---

## 📂 Estrutura do Projeto
- `sagittarius_a_predecolagem.ipynb` — Notebook principal com todos os códigos

---

## ▶️ Como Executar
1. Acesse [Google Colab](https://colab.research.google.com)
2. Faça upload do arquivo `.ipynb`
3. Execute as células na ordem
4. Para o chatbot de IA, configure sua chave da API do Google Gemini nas secrets do Colab
